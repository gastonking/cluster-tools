# Tetris para Terminal (Shell & Python)

Un juego completo de **Tetris clásico** con colores vibrantes ANSI, físicas, rotaciones, sistema de niveles y controles de teclado en tiempo real, diseñado para ejecutarse directamente en la terminal de Linux o macOS.

## Requisitos
- Python 3 instalado.
- Una terminal compatible con secuencias de escape ANSI y colores.

## Ejecución
1. Dale permisos de ejecución al script:
   ```bash
   chmod +x tetris.py
   ```
2. Ejecútalo:
   ```bash
   python3 tetris.py
   ```

## Controles
- **Flecha Izquierda (`←`) / Derecha (`→`)**: Mover pieza horizontalmente.
- **Flecha Arriba (`↑`)**: Rotar pieza.
- **Flecha Abajo (`↓`)**: Acelerar caída.
- **Barra Espaciadora**: Caída libre instantánea (Hard Drop).
- **`p`**: Pausar juego.
- **`q`**: Salir del juego.
